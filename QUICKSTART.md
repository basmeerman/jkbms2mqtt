# Quick start — bridge + dashboard in a few minutes

The goal: live JK-BMS data **and** a full dashboard in Home Assistant with as
little manual work as possible. Entities appear automatically (MQTT discovery);
the dashboard is auto-generated by the add-on — you only do a one-time config
block and install the frontend cards.

## 1. Install the add-on

**Settings → Add-ons → Add-on Store → ⋮ → Repositories**, paste
`https://github.com/basmeerman/jkbms2mqtt`, **Add**. Then install **jkbms2mqtt**.

## 2. Configure and start

In the add-on **Configuration**:

- **TCP gateway:** `transport: tcp_gateway`, set `gateway_host` / `gateway_port`
  (gateway in *transparent* mode, not Modbus-TCP). **USB:** `transport: usb_serial`
  + `jkbms_path`.
- `bms_ids`: the DIP-switch addresses on your bus, e.g. `1,2,3,4,5,6`.
- Leave `install_dashboard: true` (default). Set `dashboard_cells` to your pack
  size if not 16.

**Start** the add-on. Within a poll cycle, **Settings → Devices** shows
`BMS_1 … BMS_n` with all their entities — no dashboard YAML needed for this part.

## 3. Install the HACS frontend cards (once)

[HACS](https://hacs.xyz/) → Frontend → install **Mushroom**, **bar-card**,
**entity-progress-card**, **stack-in-card**, then **restart Home Assistant**.

## 4. Show the dashboard (one-time config block)

The add-on has already written `<config>/jkbms2mqtt/dashboard.yaml` +
`packages/jkbms_aggregates.yaml`. Add this to `configuration.yaml` and restart HA:

```yaml
homeassistant:
  packages: !include_dir_named jkbms2mqtt/packages
lovelace:
  dashboards:
    jkbms2mqtt:
      mode: yaml
      title: JK-BMS
      icon: mdi:battery
      show_in_sidebar: true
      filename: jkbms2mqtt/dashboard.yaml
```

A **JK-BMS** dashboard appears in the sidebar — bank summary + a tile per pack,
with a detail page per pack. Change `bms_ids` later and restart the add-on; the
dashboard regenerates with no re-paste.

## That's it

Optional:

- **Controls (writes):** flip `enable_basic_writes` / `enable_safety_writes` to
  make the settings editable. ⚠️ Safety thresholds can damage cells if wrong.
- **Bank aggregates:** the package adds `binary_sensor.jkbms_any_alarm` and bank
  power / current / min-SoC / max-temp sensors (used by the summary row).
- **Existing installs** whose entity ids look like `sensor.bms_1_total_pack_voltage`
  (sticky legacy names): set `install_dashboard: false` and generate manually
  with `--naming legacy` — see [`dashboards/README.md`](dashboards/README.md).
