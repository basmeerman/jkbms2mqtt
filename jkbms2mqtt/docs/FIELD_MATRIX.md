# Field matrix — spec vs implementations

Generated by [`scripts/build_field_matrix.py`](../scripts/build_field_matrix.py) 
from five primary sources:

1. **V1.0** — [`specifications/BMS.RS485.Modbus.V1.0.pdf`](specifications/BMS.RS485.Modbus.V1.0.pdf), byte offsets hand-transcribed.
2. **V1.1** — [`specifications/BMS.RS485.Modbus.V1.1.pdf`](specifications/BMS.RS485.Modbus.V1.1.pdf), byte offsets hand-transcribed.
3. **This repo** — `RegisterDef.address` (settings) or `_OFF_*: Final = …` (RT / info) in our protocol modules. Byte = `(reg − block_base) × 2` for settings/info; byte = `buffer_offset × 2` for the stitched RT block.
4. **Phinix-org** — [Multiple-JK-BMS-by-Modbus-RS485](https://github.com/phinix-org/Multiple-JK-BMS-by-Modbus-RS485). Each YAML defines either `address` alone or `address + offset`; both literal numbers shown, plus the implied spec byte they map to.
5. **Jean** — [`upstream_reference/trame_specs.json`](../../upstream_reference/trame_specs.json), the field map for the proprietary 0x55AAEB90 BLE/UART frame Jean's Node-RED add-on uses. **Different protocol.** Jean's frame byte = spec byte + 6 (header). Little-endian.

`—` = field not present / not decoded in that source.

## How phinix's two address conventions compare

- Files under `include/backup/sensors/` and `include/devel/sensors/` write
  `address: <block_base>` together with `offset: <byte>`. Under ESPHome's
  modbus_controller semantics that targets the same register that
  spec_byte_offset → block_base + byte/2 yields. Matrix shows: 
  `addr=0xNNNN off=0xMM`, spec byte = `0xMM`.
- Files under `include/backup/numbers/` and `include/modules/numbers/` write
  `address: <block_base + spec_byte>` directly (no `offset:`). That's a
  register-count interpretation: `spec_byte` is treated as a Modbus reg
  increment, addressing the register `block_base + spec_byte` — which is
  *not* the same Modbus register that the spec byte-offset interpretation
  yields. Matrix shows: `addr=0xNNNN`, spec byte = `(addr − base) × 2`.

If the two interpretations were equivalent the matrix would show the same
spec byte in both rows. Where they differ, that is a real disagreement.
